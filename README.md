# KostenKlar 
Webanwendung zur Verwaltung von Einnahmen und Ausgaben mit Monatsübersicht sowie einem Kreisdiagramm zur Visualisierung der Ausgaben des ausgewählten Monats.
# Projektbeschreibung
Uni-Projekt im 1. Semester im Fach Webtechnologien.
# Technologie-Stack 
- PHP

- CSS

- Bootstrap

- MySQL(phpMyAdmin)

- MAMP oder XAMPP

# Starten
	1.	Repository klonen
	2.	Server mit MAMP oder XAMPP starten
    3.  Datenbank über den bereitgestellten db_dump in phpMyAdmin importieren
	4.	Projekt im Browser über die lokale URL öffnen
